# HumS AI Guide A to Z

A field guide for organizations that want to adopt AI agents securely: what agents are, how
they get attacked, how to build and run them safely, and how to roll them out across a
company, from a solo founder to a large enterprise, on your own hardware or on AWS.

> **Status:** setting up. The repository structure, licenses and tooling come first; the
> guide itself will be published here later. See [HISTORY.md](HISTORY.md) for the real
> timeline.

## What it will contain

- The guide itself: 40 chapters in four books (Understand, Build, Run and Defend, Lead)
  plus a reference section, built to PDF from source. See [STRUCTURE.md](STRUCTURE.md).
- Every code example as a real file, with a test suite that runs it.
- The verification trail: what was checked, against which source, and what was corrected.
